# Mission Clean Orbit  
# Digital T Level Core Skills Mapping

## Audience and purpose
This document supports FE lecturers and school teachers in mapping **Mission Clean Orbit** to Digital T Level core expectations. It identifies workshop activities, technical capability development and observable evidence suitable for teaching, assessment and portfolio documentation.

---

## 1. Problem Solving
### Description
Learners analyse a real-world challenge (orbital sustainability), break it into manageable tasks and design practical dashboard solutions.

### Activities in the workshop
- Designing dashboard solutions for identified user needs.
- Interpreting satellite and debris data.
- Making recommendations based on findings.

### Skills developed
- Problem decomposition
- Decision-making using evidence
- Prioritisation under time constraints
- Evaluating alternative approaches

### Evidence that teachers can observe
- Structured team plans and role allocation.
- Justification of chosen technical solutions.
- Recommendation statements linked to data outputs.

---

## 2. Programming
### Description
Learners implement front-end logic using JavaScript to deliver functional dashboard features.

### Activities in the workshop
- JavaScript development for dashboard modules.
- Use of functions and variables.
- API or dataset interaction.
- Event handling for user controls.

### Skills developed
- Procedural and modular coding
- Variable scope and data handling
- Function design and reuse
- Event-driven programming practices

### Evidence that teachers can observe
- Working JavaScript in repository files.
- Features responding correctly to user interaction.
- Student explanations of how code sections operate.

---

## 3. Data
### Description
Learners work with JSON datasets to produce meaningful, interpretable outputs.

### Activities in the workshop
- Processing JSON datasets.
- Visualising key information.
- Performing calculations.
- Creating simple predictions.

### Skills developed
- Data extraction and transformation
- Quantitative reasoning
- Pattern and trend interpretation
- Communicating uncertainty and assumptions

### Evidence that teachers can observe
- Correctly transformed values shown in dashboard components.
- Calculated metrics and trend indicators.
- Student commentary on data quality and interpretation limits.

---

## 4. Digital Environment
### Description
Learners use contemporary digital tooling to build and deploy web solutions.

### Activities in the workshop
- Using GitHub for version control and collaboration.
- Publishing through GitHub Pages.
- Building browser-based applications.
- Applying core web technologies.

### Skills developed
- Repository management basics
- Branching/merging awareness (as appropriate to level)
- Deployment workflow understanding
- Practical HTML/CSS/JavaScript integration

### Evidence that teachers can observe
- Repository commit history showing contribution.
- Successful live deployment on GitHub Pages.
- Functional web application accessible via browser.

---

## 5. Security
### Description
Learners consider data trust, validation and responsible information handling within digital solutions.

### Activities in the workshop
- Data validation in code.
- Responsible use and representation of information.
- Consideration of secure systems and risks.

### Skills developed
- Input and data integrity checks
- Security-conscious thinking in design decisions
- Awareness of source credibility and misuse risks

### Evidence that teachers can observe
- Validation logic and defensive checks in scripts.
- Informed discussion of trusted data sources.
- Student recognition of secure development considerations.

---

## 6. Testing
### Description
Learners verify that dashboard components and calculations behave as expected.

### Activities in the workshop
- Debugging code.
- Functional testing of features.
- Verification of calculations and outputs.

### Skills developed
- Fault diagnosis and correction
- Test planning under time limits
- Output checking and confidence-building

### Evidence that teachers can observe
- Documented or verbal test cases.
- Before/after examples of bug fixes.
- Improved reliability in integrated dashboard behaviour.

---

## 7. Emerging Technologies
### Description
Learners engage with contemporary, cross-disciplinary themes at the intersection of digital and space sectors.

### Activities in the workshop
- Exploring satellite technology contexts.
- Considering space sustainability challenges.
- Applying data analytics techniques.
- Using simple predictive modelling ideas.

### Skills developed
- Technology horizon awareness
- Systems thinking
- Translating technical insight to societal impact

### Evidence that teachers can observe
- Student discussion linking technology to real-world outcomes.
- Recommendations framed around sustainability impact.
- Awareness of future-facing digital roles and trends.

---

## 8. Collaboration and Communication
### Description
Learners work in specialist teams and communicate technical outcomes clearly to mixed audiences.

### Activities in the workshop
- Team ownership of dashboard components.
- Presenting findings.
- Explaining technical decisions.

### Skills developed
- Team coordination and accountability
- Technical communication
- Presentation and audience awareness
- Reflective evaluation and peer feedback

### Evidence that teachers can observe
- Clear team role fulfilment and hand-offs.
- Coherent group presentations.
- Accurate explanation of decisions, trade-offs and results.

## Careers and Industry Relevance
Mission Clean Orbit aligns with current and emerging pathways across the digital economy:

- **Software Engineering**: building maintainable front-end features and integrating modules.
- **Data Analysis**: cleaning, interpreting and communicating trend-based information.
- **Cyber Security**: evaluating trust, integrity and secure handling of digital data.
- **Aerospace Technology**: understanding operational data in a space-sector context.
- **Sustainability and ESG**: using digital tools to support responsible, evidence-led decisions.
- **AI and Predictive Analytics**: introducing forecasting logic and data-informed recommendation making.

The project also strengthens employability behaviours valued across sectors: teamwork, communication, adaptability, professionalism and digital confidence.
