# Mission Clean Orbit  
# BTEC Computing Skills Mapping

## Audience and purpose
This document maps the **Mission Clean Orbit** workshop to core BTEC Computing skill areas. It is written for FE lecturers and school teachers who need clear evidence of technical, academic and employability skill development.

---

## 1. Software Development
### Demonstrated through
- Developing JavaScript solutions
- Creating dashboard features
- Testing functionality
- User interface design

### Relevant skills
- Writing and structuring JavaScript code
- Decomposing a brief into manageable development tasks
- Implementing functions, variables and event handlers
- Applying iterative improvement through test-feedback-fix cycles
- Producing maintainable, readable code

### Example student activities
- Build dashboard cards that display selected metrics.
- Create functions to transform raw JSON values into user-friendly outputs.
- Add interaction features (for example filters, buttons or drop-down controls).
- Debug logic and correct issues identified during integration.

### Expected evidence of learning
- Working code committed to repository files.
- Functional dashboard components that meet team requirements.
- Testing notes or verbal explanation of defects and fixes.
- Student rationale for design and implementation choices.

---

## 2. Data Modelling
### Demonstrated through
- Consuming JSON data
- Organising and processing datasets
- Working with real-world information
- Interpreting trends

### Relevant skills
- Understanding data structures (objects, arrays, key-value pairs)
- Cleaning and validating incoming data
- Selecting relevant fields for analysis and visualisation
- Applying calculations to generate indicators
- Interpreting outputs and limitations of data

### Example student activities
- Import and parse a JSON dataset.
- Identify missing, duplicate or anomalous values.
- Derive totals, ratios or trend indicators.
- Compare outputs over time and highlight emerging patterns.

### Expected evidence of learning
- Data processing logic in JavaScript.
- Accurate calculations displayed in the dashboard.
- Commentary that links outputs to sustainability insights.
- Teacher observation of students discussing data quality and assumptions.

---

## 3. Human Computer Interaction
### Demonstrated through
- Dashboard design
- Data visualisation
- Colour and layout decisions
- User-centred design

### Relevant skills
- Designing interfaces for specific audiences
- Selecting appropriate visual formats for data type and message
- Applying accessibility principles (contrast, readability, structure)
- Balancing information density with usability

### Example student activities
- Prototype a dashboard section before implementation.
- Choose colours and labels to improve clarity.
- Reorganise layout based on peer feedback.
- Add explanatory text to support non-technical users.

### Expected evidence of learning
- UI layouts and component designs in the final product.
- Improved readability and consistency after iteration.
- Student justification for visual choices.
- Peer/teacher feedback notes on usability.

---

## 4. Project Management
### Demonstrated through
- Team-based development
- Defined responsibilities
- Collaborative problem solving
- Delivering a working product

### Relevant skills
- Task allocation and role ownership
- Time management within fixed workshop constraints
- Communication across team boundaries
- Managing dependencies and integration points
- Prioritising essential functionality for delivery

### Example student activities
- Assign team roles at project launch.
- Use short stand-up updates during development.
- Coordinate data and code hand-offs between teams.
- Agree a final integration checklist before presentation.

### Expected evidence of learning
- Observable role fulfilment and contribution.
- Delivery of agreed outputs within timeframe.
- Evidence of collaborative troubleshooting.
- Final integrated dashboard demonstrated to class.

---

## 5. Cyber Security Awareness
### Demonstrated through
- Discussion of trusted data sources
- API usage
- Data integrity
- Secure development considerations

### Relevant skills
- Recognising trusted versus untrusted data inputs
- Applying basic validation and defensive coding
- Understanding risks of exposing sensitive information
- Considering integrity, provenance and reliability of sources

### Example student activities
- Evaluate whether a data source is credible.
- Add input/data checks before displaying values.
- Discuss what should and should not be stored client-side.
- Identify potential misuse or misinterpretation of data outputs.

### Expected evidence of learning
- Student explanations of security choices and risks.
- Validation logic present in code.
- Documented or verbal consideration of secure-by-design principles.
- Informed discussion on data integrity and responsible use.

## Teaching portfolio notes
Mission Clean Orbit provides strong evidence for:

- technical capability in software and data,
- digital employability skills (communication, collaboration, accountability),
- authentic project workflow experience,
- reflective practice through presentation and evaluation.

It can be used as an applied, portfolio-ready activity that bridges classroom computing with current sustainability and industry themes.
