# Team 4 Starter Task - Insights and Recommendations

## Team mission
Translate metrics into clear sustainability insights for stakeholders.

## Student starter tasks
1. Open `script.js` and inspect `buildInsights()`.
2. Replace generic statements with rule-based recommendations linked to metrics.
3. Add logic so recommendations change when risk levels change.
4. Ensure each recommendation:
   - references evidence from the dashboard,
   - uses clear language for non-technical audiences,
   - includes an action.
5. Add one short "executive summary" sentence at the top of insights.

## Success criteria (how you know you have succeeded)
- Insight text updates when filters or metrics change.
- Recommendations are evidence-based and actionable.
- Another team can explain the recommendation logic.
- Final messages are appropriate for policy or operations stakeholders.

## Suggested stretch task
Add a confidence label (high/medium/low) based on dataset completeness.
