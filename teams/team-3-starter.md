# Team 3 Starter Task - Visualisation and UI

## Team mission
Make data easy to understand through clear, accessible visual design.

## Student starter tasks
1. Open `styles.css` and improve readability and visual hierarchy.
2. Open `script.js` and extend `renderVisualSummary()`.
3. Add one additional visual component, such as:
   - orbit distribution bars,
   - status comparison chart,
   - simple table for top findings.
4. Add labels and units so non-technical users can interpret values.
5. Check colour contrast and ensure information is not colour-only.
6. Test layout on narrow screen width and adjust CSS if needed.

## Success criteria (how you know you have succeeded)
- At least one additional visual component appears and updates correctly.
- Users can interpret visuals without reading code.
- Layout remains readable on desktop and mobile widths.
- Team can justify design choices in presentation.

## Suggested stretch task
Add a toggle to switch between compact and detailed dashboard view.
